# DaxPay 开源支付系统

`DaxPay` 开源版是一款基于 `GNU LGPL v3.0` 协议分发的开源支付系统,提供支付、退款、转账等支付相关的核心能力。

## 它解决什么问题

业务系统对接多种支付方式(支付宝、微信、银联等)通常面临:

- 各通道接口规范、签名算法、回调机制各不相同,对接成本高
- 多通道的运维、升级、故障切换难以统一管理
- 商户与服务商的多租户、分账、对账逻辑复杂

DaxPay 将各通道封装为**统一的 HTTP 接口**,业务系统只需对接一套标准协议,即可接入多种支付方式,显著降低对接与运维复杂度。

## 核心特性

- 支持支付、退款、转账等支付核心能力
- 提供商户端、运营端,支持多商户和服务商模式
- 封装各通道为统一的 HTTP 接口,方便业务系统对接
- 接口请求与响应数据支持 RSA / SM2 签名机制,保证交易安全可靠

## 项目组成

DaxPay 是一个 monorepo,由多个子项目协同构成:

| 子项目 | 说明 |
| ------ | ---- |
| `dax-pay-open` | 主后端应用(Java / Spring Boot) |
| `dax-pay-channel-one` | 通道适配子应用,对接单一第三方支付渠道 |
| `dax-pay-iot` | IoT 硬件通信子应用(云音箱等设备) |
| `dax-pay-ui` | Web 管理端(运营端 / 商户端) |
| `dax-pay-h5` | 移动 H5 端(收银台) |
