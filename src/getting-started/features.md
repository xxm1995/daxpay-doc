description: DaxPay 的功能亮点
---

## 支付核心能力

- **支付**:统一下单,支持主流支付渠道
- **退款**:支持全额 / 部分退款
- **转账**:资金转账能力
- **查询**:订单状态、交易明细查询
- **对账**:交易对账与差异处理
- **回调**:异步通知机制,保证最终一致性

## 多租户体系

- **商户端**:商户入驻、信息管理、支付产品配置
- **运营端**:平台运营管理
- **服务商模式**:支持服务商(ISV)接入
- **代理商模式**:代理商管理与配置

## 通道统一封装

- 各通道(支付宝、微信、银联商务、拉卡拉等)封装为统一 HTTP 接口
- 通道 SDK 依赖隔离,支持独立部署、独立升级、弹性伸缩
- 新通道接入有标准模板工程可循

## 安全机制

- RSA / SM2 公私钥签名,保证请求与响应不可篡改
- Sa-Token 权限认证(token name: `Accesstoken`)
- 凭证强制环境变量注入(生产环境)

## 国际化与时区

- 中英文国际化支持
- 时间字段统一使用 `timestamptz`,实体使用 `OffsetDateTime`,时区统一 UTC
