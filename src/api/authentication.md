## 权限认证

DaxPay 使用 [Sa-Token](https://sa-token.cc/) 进行权限认证:

- **Token Name**:`Accesstoken`(请求头)
- 通过 token 进行身份校验与权限控制

## 请求签名

接口请求与响应数据支持 **RSA / SM2** 公私钥签名机制,保证交易安全可靠:

- 请求参数使用商户私钥签名,服务端用商户公钥验签
- 响应数据使用平台私钥签名,商户用平台公钥验签
- 防止请求与响应被篡改
