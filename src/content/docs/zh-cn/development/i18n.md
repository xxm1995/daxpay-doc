前后端均需国际化,国际化处加中文注释。

## 后端 i18n

### 资源文件位置

```
daxpay-platform/daxpay-platform-common/common-i18n/src/main/resources/i18n/{locale}/
├── zh-CN/
└── en-US/
```

### message key 命名

| 层级 | 风格 | 示例 |
| ---- | ---- | ---- |
| 多词文件名、枚举项 code | `snake_case` | `pay_route` |
| 业务消息叶子 key | `camelCase` | `pay.route.error.noMatch` |
| validation 字段与约束 | `camelCase` | `validation.field.bizOrderNo.notBlank` |

### 消息源机制

- 自定义 `JsonMessageSource` 扫描 `classpath*:i18n/{locale}/**/*.json`
- 文件路径映射为 key 前缀(如 `channel/error.json` → `channel.error.*`)
- locale 由请求头 `Accept-Language` 决定(zh-CN / en-US)

### 使用方式

- 枚举实现 `I18nSupport` 仅保留 `code`,中文说明写在 `///` 注释与 `enum/*.json`
- 业务异常用 messageKey:`new BizInfoException(code, "pay.route.error.noMatch")`
- Bean Validation 注解 `message` 用 i18n key:`{validation.field.{字段名}.{约束}}`

:::note
新增翻译需**同时维护 `zh-CN` 与 `en-US`**。
:::

## 前端 i18n

### Web 管理端

翻译文件按业务模块拆分,位于 `packages/locales/src/langs/{locale}/`:

```
langs/
├── en-US/   # core / iam / payment / risk / system
└── zh-CN/
```

### H5 端

移动端与 PC 端各自维护语言包,公共文案集中在 `src/shared/`。
