`dax-pay-h5` 是 DaxPay 开源版的移动端网关应用,承载收银台等移动端页面。

## 双端支持(PC / 移动)

单应用同时承载 PC 与移动端两套**完全独立**的页面,由入口设备分发:

- **设备探测**:`index.html` 在 Vue 挂载前写入 `window.__DEVICE__`(`'pc' | 'mobile'`),开发期可用 `?device=pc|mobile` 强制覆盖,零闪烁
- **目录划分**:移动端代码在 `src/mobile/`,PC 端在 `src/pc/`,公共代码在 `src/shared/`
- **移动适配**:使用 `postcss-mobile-forever` 做移动端适配

## 技术栈

| 技术 | 版本 | 说明 |
| ---- | ---- | ---- |
| Vue | 3.5 | 前端框架 |
| Vite | 8.x | 构建工具 |
| Vue Router | 5.x | 路由(hash 模式) |
| Vant | 4.x | 移动端 UI 组件库 |
| UnoCSS | 66.x | 原子化 CSS |
| Pinia | 3.x | 状态管理 |

## 启动

```bash
cd dax-pay-h5
pnpm install
pnpm run dev          # 端口 9100
pnpm run build
pnpm run type:check   # 类型检查
```

## 环境要求

| 环境 | 版本 | 备注 |
| ---- | ---- | ---- |
| Node | ^22.13.0 \|\| ^24.0.0 | 仅支持 LTS(22/24) |
| pnpm | >=10.0.0 | 强制 pnpm(禁用 npm/yarn) |

> 项目通过 `packageManager` 字段锁定 pnpm 版本,启用 corepack 后会自动切换。
